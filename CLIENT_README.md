# Client / Small AI Agency Readme

## Audience

This document is for a potential client or small AI agency evaluating whether I can help with RAG and autonomous-agent security-readiness work.

## What I can help with now

I can help teams prepare AI systems for responsible review by creating clear readiness gates, evidence packages, demo attack coverage, and claim boundaries. The strongest fit is pre-launch or pre-partner-review work where the team needs an honest view of risks, evidence, and gaps before making stronger claims.

## What this repo demonstrates

This repository demonstrates:

- RAG and agent security-readiness thinking;
- reviewer-facing evidence packaging;
- claim-boundary governance;
- synthetic prompt-injection, retrieved-content prompt-injection, and agent-risk demos;
- isolated Python security helpers and pytest checks;

## What I cannot claim yet

This repo is portfolio/demo evidence. It is not a managed production security guarantee. It does not claim:

- production readiness;
- enterprise readiness;
- compliance certification;
- external validation;
- full Onyx live staging;
- live enforcement, live blocking, or live filtering.
