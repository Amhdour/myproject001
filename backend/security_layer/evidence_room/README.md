# Partner Evidence Room Helpers

This package contains isolated helper models and in-memory manifest builders for the Step 30X partner evidence room bundle.

## Safety boundary

- Does not enable enforce mode.
- Does not enable shadow-deny runtime mode.
- Does not add live blocking.
- Does not add live filtering.
- Does not wire application request paths or change application behavior.
- Does not claim production readiness, external validation, or compliance certification.

The helpers exist only to keep partner-facing documentation and evidence indexes consistent.
