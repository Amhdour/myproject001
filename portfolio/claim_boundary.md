# Claim Boundary

This project is a portfolio and partner-demo evidence package for RAG and autonomous-agent security readiness. It is not an enterprise production deployment.

## Safe claims

The project may be described as:

- AI security-readiness portfolio.
- Onyx-based RAG/agent security case study.
- Isolated security-control helpers and tests.
- Retrieved-content prompt-injection detection covered by focused tests and synthetic demo evidence.
- Evidence-room and launch-gate discipline.
- Minimal staging evidence only where documented.
- Production-style demo.

## Forbidden claims

The project must not be described as:

- Production-ready.
- Enterprise-ready.
- Compliance-certified.
- Externally validated.
- Full live Onyx staging.
- Full prompt-injection defense.
- Live enforce-mode protection.
- Live shadow-deny runtime.
- Live blocking/filtering.
- Production monitoring/rollback/backup unless specific evidence exists.

- "This repository demonstrates a security-readiness portfolio around an Onyx-based RAG/agent system."
- "The security-layer tests demonstrate isolated helper behavior and narrow real-path hook wiring only."
