# Repository Hygiene Checklist

Use this checklist before sharing the repository with AI agencies, employers, partners, clients, or public reviewers.

## Portfolio and Evidence Hygiene

- [ ] README has clear portfolio positioning.
- [ ] Portfolio package exists.
- [ ] Case study exists.
- [ ] Claim boundary exists.
- [ ] CI workflows exist.
- [ ] Demo attack runner exists.
- [ ] Evidence index exists.
- [ ] Release-prep package exists.
- [ ] Known limitations are visible.
- [ ] NO-GO / PENDING / NOT CLAIMED boundaries are visible.
- [ ] No secrets or real customer data.
- [ ] No fake screenshots or fake deployment evidence.
- [ ] Upstream Onyx attribution/license links preserved.
- [ ] Reviewer path is clear within 3 clicks.

## Manual Review Notes

This checklist is a pre-share hygiene aid. It does not prove production readiness, enterprise readiness, external validation, compliance certification, full Onyx live staging, live enforcement, live blocking, or live filtering.
