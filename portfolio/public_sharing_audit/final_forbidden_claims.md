# Final Forbidden Claims

The following are forbidden claims and must not be used as positive public claims for this portfolio:

- “Enterprise-ready.”
- “Production-ready.”
- “Certified.”
- “Externally validated.”
- “Fully secure.”
- “Guaranteed secure.”
- “Live enforcement protects production.”
- “Full Onyx staging proven.”
- “Compliance-ready.”
- “SOC 2 / ISO / GDPR / HIPAA compliant.”

## Safe Interpretation

This file lists forbidden claims for review and filtering. It is not making those claims. Keep production readiness as NO-GO, enterprise readiness as NO-GO, external validation as PENDING, and compliance certification as NOT CLAIMED.
