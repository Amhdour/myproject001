# Attribution and License Check

## Upstream Onyx Attribution Check

This repository is based on upstream [Onyx](https://github.com/onyx-dot-app/onyx). Public sharing must preserve clear attribution that the upstream Onyx project provides the base RAG/agent platform, connectors, product architecture, and application foundation.

## MIT License Check

If the applicable upstream Onyx files are MIT licensed, preserve the upstream license notices and links. Do not remove license files, copyright notices, or attribution links when preparing the portfolio for sharing.

## Separation of Upstream Platform and Portfolio Contribution

Public descriptions should clearly separate:

- **Upstream platform:** Onyx application foundation, RAG/agent capabilities, connectors, and existing architecture.
- **Portfolio contribution:** AI security-readiness documentation, evidence packages, claim-boundary checks, demo attacks, release-prep materials, and isolated security-layer validation where repository evidence supports it.

## Non-Ownership and Non-Endorsement Boundary

- Do not claim ownership of upstream Onyx.
- Do not claim official Onyx endorsement unless repository evidence exists.
- Do not imply this portfolio is an official Onyx security certification, compliance assessment, or production-readiness statement.

## Preservation Reminder

Before sharing, confirm upstream license and contribution links remain visible in the root README, portfolio materials, and any public-facing summaries.
