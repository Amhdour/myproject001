# Publication Readiness Checklist

Complete this checklist before making the repository public or sharing it with agencies, employers, partners, or reviewers.

- [ ] No secrets are present.
- [ ] No private IPs are present.
- [ ] No real credentials are present.
- [ ] No real customer data is present.
- [ ] No unsafe production claims are present.
- [ ] CI is passing for the commit being shared.
- [ ] Demo runner is passing for the commit being shared.
- [ ] Evidence links are valid.
- [ ] License and upstream attribution are preserved.
- [ ] Claim boundary is visible near the top of the reviewer path.
- [ ] README reviewer path is clear.
- [ ] Optional screenshots, if included, are manually captured and sanitized.
- [ ] Optional video, if included, is manually recorded and sanitized.
- [ ] Production readiness remains NO-GO.
- [ ] Enterprise readiness remains NO-GO.
- [ ] External validation remains PENDING unless real external validation evidence exists.
- [ ] Compliance certification remains NOT CLAIMED.
- [ ] Full Onyx live staging remains NOT CLAIMED unless real evidence exists.
- [ ] Live enforcement, live blocking, and live filtering remain NOT CLAIMED.
