## Architecture summary

- The portfolio uses security-specific helpers to keep runtime decisions, evidence emission, and sanitization separate.
- Optional adapters and external tools are treated as bounded paths with explicit fallback behavior.
- Evidence documents are separated from code so the repository can show proof without overclaiming deployment maturity.
