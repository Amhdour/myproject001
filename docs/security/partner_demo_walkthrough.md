# Partner Demo Walkthrough

## Demo scope

This walkthrough is suitable for a partner-facing evidence review of documented controls, test evidence, limitations, and next steps.

## Script

1. Open the partner evidence room overview.
2. Review safe claims and required non-claims.
3. Review control coverage at a summary level.
4. Review the test evidence index and captured test outputs.
5. Review demo attack summaries as documentation-only evidence.
6. Review limitations and next steps.
7. Finish with the partner go/no-go decision.

## Guardrails

Do not present this walkthrough as a live production validation, external assessment, compliance audit, or certification review. Do not imply live blocking/filtering or enforce-mode activation.
