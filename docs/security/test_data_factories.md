# Test Data Factories and Fixtures Plan (Step 9)

Status: planned only. No fixture code implemented.

## Scope
This planning artifact defines test data factories and fixtures required for upcoming security validation work. It is documentation-only and does not change runtime behavior.

## Global Safety Rules
- Use deterministic fake IDs (`tdf_*`) and synthetic domains (`example.test`).
- Use fake tokens/secrets with explicit non-production markers (for example `fake_secret_not_real_*`).
- Never include real tenant, user, customer, document, credential, connector, or production audit payload data.
- All fixture implementation status values remain `planned`.
