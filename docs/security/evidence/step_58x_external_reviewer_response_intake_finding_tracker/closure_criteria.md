# Closure Criteria

Reviewer findings must be closed with evidence and bounded claims.

## Closure Rules

- Findings cannot be closed by assertion only.
- Closure requires evidence.
- Critical/high findings require retest evidence.
- If a finding affects a claim, the claim must be downgraded until fixed.
- Reviewer approval is not assumed unless explicitly provided.
- Accepted risk requires rationale and bounded claim wording.

## Minimum Closure Record

Each closed or rejected finding should include:

- Finding ID.
- Final status.
- Evidence path or rationale path.
- Retest evidence path for critical/high findings.
- Claim-boundary update if the finding affected a claim.
- Closure date.
- Owner or reviewer of closure.
