# RAG Security Evaluation Evidence

This directory contains the local fixture-based foundation for evaluating RAG security behavior and documenting regression coverage for Ragas-style metrics and promptfoo-style CI cases.

## What is included

- Synthetic fixture datasets under `datasets/`.
- Local evaluation metrics implemented in `backend/onyx/security_layer/evaluations/`.
- A demo/eval script at `scripts/security/evaluations/run_rag_security_eval.py`.
- Evidence artifacts generated by the demo/eval script:
  - `eval_results.md`
  - `limitations.md`
  - `reproduction_commands.md`
  - `promptfoo_cases.yaml`

## Scope

This is a lightweight foundation only. It is designed for fixture-based local evaluation and CI regression preparation.

## Claim boundary

- No production readiness claim is made.
- PyRIT and garak are not added.
- OPA, scanner, tool governance, MCP governance, and gateway governance behavior are unchanged.
- Ragas and promptfoo remain optional dependencies.

## How to use it

Run the demo/eval script from the repository root:

```bash
python scripts/security/evaluations/run_rag_security_eval.py
```

If the optional Ragas Python package or promptfoo CLI is unavailable, the script still completes using the local fixture-based evaluator and records the limitation in the evidence docs.
